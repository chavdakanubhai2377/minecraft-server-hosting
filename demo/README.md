# Eagle Host — Demo Test Site

This directory contains a simple static demo page that simulates the Eagle Host checkout flow. It does not process real payments — it only demonstrates the UX and redirects to the Eagle Host Discord invite after "payment".

To view the demo locally:

1. Open demo/index.html in your browser (double-click or serve it with a static server).
2. Choose a plan, enter an email (optional), and click "Simulate Payment".
3. You will be redirected to https://discord.gg/gepDqrQft
